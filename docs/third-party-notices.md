# Sources and licenses

echo is a GPL-3.0 fork of Michał Rogalski's [mafik/echo](https://github.com/mafik/echo). Original history and [LICENSE.txt](../LICENSE.txt) are retained. Adapted classes retain source comments. Exact revisions, modifications and replacement decisions are in [the ledger](integration-ledger.md) and [source refs](source-refs.json).

Adapted work includes Artur Linnik's Toldya waveform/UI behavior; shkarlsson/good-echo packet-history design; spidey000/saidIT exporter/save fixes; mikenrafter/echo history/automation/activity behavior; overlapping ElliotBadinger autosave/threading behavior; and copa-sh/echo's Java GPS, keyword, survey, camera and screen tools. Copa's uncompiled Kotlin migration was not imported. Relative-motion/widest-camera refinements use its exact `2a53be2b1744d9e79e3f46d7b5c158d61a5a951e` branch revision. All source adaptations remain under echo's GPL license.

License texts/copyrights ship in `app/src/main/assets/licenses` and are readable through Settings → About echo → Open-source licenses. `MapLibre.txt` is the unmodified [Android license bundle at android-v13.7.1](https://github.com/maplibre/maplibre-native/blob/android-v13.7.1/platform/android/LICENSE.md). Map rendering is based in part on the work of the [FreeType Team](https://freetype.org/). No private signing key or credentials are in the repository. The small Silero VAD model is bundled; the Vosk transcription model remains an optional download.

`app/src/androidTest/assets/spoken-digits.pcm` is a test-only resampling of [Vosk's example test.wav](https://github.com/alphacep/vosk-api/blob/master/python/example/test.wav), from its Apache-2.0 source distribution. Transformation: mono signed PCM16, 48 kHz; quiet-speech tests divide samples by 50. It is not bundled in the normal debug/release app. Synthetic format, playback and storage fixtures are generated by tests.

`camera-back.pcm` and `camera-front.pcm` are test-only synthesized utterances of the default commands, generated using eSpeak NG 1.52.0 with the English-US voice at 135 words/minute, resampled to mono PCM16 at 48 kHz with leading/trailing silence. No eSpeak code or voice database is distributed. These fixtures are absent from the normal app.
